## A. Scope

Replace Backlog Hygiene Rules item 2 in `docs/system/issue-resolution-rules.md` with a mechanically enforced **Completion Authority Binding** section that:

1. Requires a PASS artifact (containing `"Verdict: PASS"`) to exist before committing Regular P-### archival.
2. Requires both Stage-1 and Stage-2 PASS artifacts (each containing `"Verdict: PASS"`) to exist before committing Inventory P-### archival, with Stage-2 explicitly referencing Stage-1.
3. Requires commits moving P-### to archive to reference the relevant PASS artifact filename(s).
4. Adds BOUNDED state enforcement with a pre-commit HALT condition requiring literal match of `"Verdict: PASS"`.

**Closes**: WP-3 — Completion authority not mechanically bound; P-### archival sequencing stated but not enforced before commit.

### Non-Goals

- Does NOT rename `"Verdict: PASS/FAIL"` to `"Verification: PASS/FAIL"`.
- Does NOT modify verification templates.
- Does NOT migrate or rewrite existing verification artifacts.
- Does NOT alter Stage-1 or Stage-2 artifact structure.
- Terminology normalization is tracked separately and is not part of Issue-003.

## D. Current State

Item 2 currently reads:

```
2. Completion authority:
   - Standard P-###: Verification PASS authorizes moving the P-### from
     `docs/system/pending-items.md` to `docs/system/pending-items-archive.md`.
   - Inventory P-###: Inventory Verification Stage 2 PASS authorizes moving
     the P-### from `docs/system/pending-items.md` to
     `docs/system/pending-items-archive.md`.
```

This states which pass authorizes completion but does not:
- Require the PASS artifact to physically exist before the archival commit
- Require the artifact to contain the "Verdict: PASS" marker
- Require the commit message to reference the PASS artifact filename
- Provide BOUNDED state enforcement with a HALT condition

## E. Proposed Change

Replace item 2 in Backlog Hygiene Rules with the following:

---

```
2. Completion authority binding:

   Regular P-###:
   - Verification PASS artifact MUST exist in docs/system/outputs/
   - Artifact MUST contain: "Verdict: PASS"
   - Commit moving P-### to archive MUST reference Verification artifact filename

   Inventory P-###:
   - Stage-1 PASS artifact MUST exist
   - Stage-2 PASS artifact MUST exist
   - Stage-2 MUST reference Stage-1 filename
   - Stage-2 MUST contain: "Verdict: PASS"
   - Commit moving P-### to archive MUST reference both artifacts

   Enforcement (BOUNDED state):
   Before committing P-### archival, verify all PASS artifacts exist and contain
   the exact string "Verdict: PASS".
   If verification fails, HALT: "Completion authority violation: [missing prerequisites]"
```

---

All other Backlog Hygiene Rules items (1, 3) are unchanged.
