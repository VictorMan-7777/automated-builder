## A. Scope

Add `{project-slug}` to `templates/project/index.md.tmpl` so that the rendered `index.md` contains the project slug, satisfying Check 12 of the end-to-end validation in `run-create-project.sh`.

**Closes**: P-016 — `run-create-project.sh` fails with "Inconsistency detected: project-slug missing in index.md", triggering cleanup on valid flag inputs.

### Non-Goals

- Does NOT modify `run-create-project.sh` validation logic.
- Does NOT modify any other template file.
- Does NOT change the slug normalization or rendering pipeline.
- Does NOT alter the project directory structure created by the script.

---

## B. Root Cause

`system/scripts/run-create-project.sh` Check 12 (line 667–669):

```bash
# Check 12: Consistency check - slug appears in index.md
if ! grep -q "${IDENTITY_SLUG}" "${PROJECT_PATH}/index.md"; then
  validation_error "Inconsistency detected: project-slug missing in index.md" true
fi
```

This check verifies that `IDENTITY_SLUG` (read from `project.yaml`) appears somewhere in `index.md`. However, `templates/project/index.md.tmpl` contains only `{Project Name}` and `{YYYY-MM-DD}` tokens — no `{project-slug}` or `{Project Slug}` token. The rendered `index.md` therefore never contains the slug, causing Check 12 to fail unconditionally and trigger the `should_cleanup=true` path, deleting the partially-created project directory.

---

## C. Target

**File**: `templates/project/index.md.tmpl`

**Change**: Add `**Slug**: {project-slug}` as a metadata field in the header section, after `**Last Updated**`.

---

## D. Current State

`templates/project/index.md.tmpl` header section (lines 1–5):

```
# {Project Name}

**Status**: Planning
**Last Updated**: {YYYY-MM-DD}
```

No `{project-slug}` token is present. The `render_template` function in `run-create-project.sh` substitutes `{project-slug}` → `ESCAPED_SLUG` and `{Project Slug}` → `ESCAPED_SLUG`, but neither token exists in this template, so the slug never appears in the rendered file.

---

## E. Proposed Change

Replace the header section of `templates/project/index.md.tmpl` (lines 1–5):

**Before**:
```
# {Project Name}

**Status**: Planning
**Last Updated**: {YYYY-MM-DD}
```

**After**:
```
# {Project Name}

**Status**: Planning
**Slug**: {project-slug}
**Last Updated**: {YYYY-MM-DD}
```

This places the slug as an explicit metadata field immediately below the Status line. The existing `render_template` function already handles `{project-slug}` substitution (`sed "s|{project-slug}|${ESCAPED_SLUG}|g"`), so no script changes are required.
